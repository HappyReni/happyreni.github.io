Agents Studio

Agents Studio는 운영자 한 명이 자기 업무를 위해 쓰는 개인용 AI 작업 도구입니다. 일반 사용자에게 제공하는 서비스가 아닙니다.

Gmail 사용

운영자가 승인함에서 정확한 받는 사람·제목·본문을 확인하고 승인한 메일만, 운영자 본인의 Gmail 계정에 초안으로 저장하거나 한 번 보냅니다. 요청하는 권한은 gmail.compose(초안 작성·발송)뿐이며 받은편지함을 읽지 않습니다.
