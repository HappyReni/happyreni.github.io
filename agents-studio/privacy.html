개인정보처리방침

시행일: 2026년 11월 24일

Agents Studio(이하 "앱")는 운영자 한 명이 자기 업무에 쓰는 개인용 도구입니다. 이 방침은 앱이 Google 사용자 데이터를 어떻게 다루는지 설명합니다.

접근하는 데이터

  • Google OAuth 범위 https://www.googleapis.com/auth/gmail.compose만 요청합니다.
  • 이 권한으로 운영자가 승인한 메일을 운영자 계정의 임시보관함에 저장하거나 보냅니다. 받은편지함의 메일은 읽지 않습니다.
  • 연결한 계정의 메일 주소를 발신자 표시와 연결 확인에 사용합니다.

저장과 보안

  • OAuth 토큰은 운영자의 Mac 로그인 키체인에만 저장하며 외부 서버로 보내지 않습니다.
  • 승인한 메일의 받는 사람·제목·본문과 실행 결과는 운영자만 접근하는 비공개 작업 기록에 남습니다.

공유와 판매

Google 사용자 데이터를 판매하거나 광고에 쓰지 않으며, 제3자에게 넘기지 않습니다. 앱이 Google API로 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

철회와 삭제

Google 계정 → 보안 → 타사 앱 액세스에서 언제든 권한을 해제할 수 있습니다. 해제하거나 연결을 끊으면 키체인의 토큰을 삭제합니다.
